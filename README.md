# DesktopFriend

A desktop pet for Windows 11: a black 3D dog (or Wingman, if you have his model) that lives on top of the taskbar. It walks around, sits, lies down and sleeps, and you have to look after it: **pet it**, **feed it** and **put it to bed**.

![Six poses of the DesktopFriend 3D dog](https://lucasprezfdez.github.io/assets/img/proyecto-desktopfriend.webp)

## Highlights

- **A transparent window that lets clicks through.** Wherever there is no dog, clicks reach whatever is underneath. Tauri can only ignore the mouse for the whole window, and a window that ignores it receives no events. So the app polls the cursor (every 30 ms near the dog, 120 ms farther away) and checks the opacity of the pixel under it to decide who gets the click ([`src/clickThrough.ts`](src/clickThrough.ts)).
- **3D models generated by script.** Blender runs in script mode (Python) to retouch and animate a CC0 base model, and to build the bed. `npm run model` regenerates the `.glb` from scratch.
- **Measured resource usage.** The frame rate adapts to what the dog is doing: 30 fps when it walks, eats or is petted, 20 when it stays still and 10 when it sleeps. On the packaged app that brought idle usage down to 1.1% of total CPU and 183 MB of private memory. The installer is 2.4 MB, against the 85–96 MB that the research found for Electron apps ([decision 0013](docs/decisiones/0013-empaquetado-y-consumo.md)).
- **Testing an app that is a transparent window.** [`tools/verify/`](tools/verify/) drives the running app through the Chrome DevTools Protocol (WebView2 remote debugging) and through PowerShell scripts that move the real cursor, to check click-through, petting, the bed sequence and the menus.
- **Every decision documented.** 30 decisions with their alternatives and reasons, a sourced comparison of frameworks and 3D pipelines, and a log of everything done (in Spanish, in [`docs/`](docs/)).

## How to use it

| You want to | Do this |
|---|---|
| Pet it | Rub the cursor over it, without clicking. It likes it more on the head |
| Feed it | Click on it and press the 🍖 circle, or use the tray icon menu |
| See how it's doing | Click on it: three circles show its fullness 🍖, happiness ❤️ and energy ⚡. The ring of each one shows the level |
| Move it | Press and drag it: a hand picks it up by the collar, lifts it facing you and carries it, swinging. When you let go it comes down and lands |
| Put it to bed | When you pick it up, its bed appears in the right corner of the screen. Drop it on top: it lies down with its head on the edge, falls asleep and recovers energy much faster than sleeping on the floor. When it's rested it gets up on its own and the bed is put away |
| Switch pets | Right-click on it, or **Cambiar de mascota** (change pet) in the tray menu: a circle appears for each pet, with its portrait. There are the dog and Wingman; both share hunger, happiness and energy |
| Move it to another screen | If you have several: **Cambiar de pantalla** (change screen) in the tray menu, or drag it there. When you reopen the app it stays on the same one |
| Bring it back | Click the tray icon, or **Traer aquí** (bring here) in its menu |
| Hide it, start it with Windows or quit | Right-click the tray icon |

Wherever there is no dog, clicks reach whatever is underneath: it doesn't get in the way.

Over time it gets hungry, bored and tired. When it's hungry or sad you can tell: it lowers its head and tail. When it runs out of energy, it sleeps wherever it is; in its bed it rests three times faster. It doesn't die: if you go days without opening the app, you'll find it hungry and downcast, nothing more.

## Install

`npm run installer` builds `DesktopFriend_0.1.0_x64-setup.exe` and leaves it in the project root. It installs per user, without administrator rights. It isn't code-signed, so Windows SmartScreen will warn you on other machines.

## Development

Requirements: Node 24, Rust (`stable-msvc` toolchain), Visual Studio 2022 C++ Build Tools and, only to regenerate the model, Blender 5.2.

```
npm install
npm run tauri dev      # the real app, with hot reload
npm run dev            # frontend only, in the browser (the desktop is simulated)
npx vitest run         # unit tests
npm run model          # regenerates public/models/dog.glb with Blender
npm run model:bed      # regenerates public/models/bed.glb (the bed) with Blender
npm run model:wingman  # regenerates public/models/wingman.glb with Blender (needs the source model)
npm run installer      # builds and leaves the installer in the project root
```

### Structure

| Path | Contents |
|---|---|
| `src/desktop.ts` | Bridge to Tauri. The only module that touches it |
| `src/clickThrough.ts` | Clicks that pass through the window where there is no dog |
| `src/scene.ts`, `src/blackFur.ts`, `src/props.ts` | 3D scene, fur, bowl, hand and bed |
| `src/pet.ts`, `src/dog.ts`, `src/wingman.ts`, `src/loadPet.ts` | What all pets share, what is specific to the dog and to Wingman, and how each one is loaded |
| `bed.html`, `src/bedWindow.ts` | Second window, which draws the bed while the dog is being carried |
| `src/needs.ts` | The pet's needs (pure functions) |
| `src/behavior.ts`, `src/interaction.ts`, `src/ui.ts` | Behavior, mouse gestures and interface |
| `src/pets.ts`, `src/petMenu.ts`, `src/portrait.ts` | Pet list, menu to switch between them and the portrait shown in it |
| `src-tauri/` | Native side: windows, tray, start with Windows |
| `tools/model/` | 3D model generation (dog, Wingman and bed) with Blender |
| `tools/verify/` | Tools to verify the running app |
| `assets/source/` | Original models and their provenance |
| `docs/` | Research, decisions and log |

### Verify the running app

Start the app with the debugging port and use the tools in `tools/verify/`:

```
$env:WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS = "--remote-debugging-port=9223"
npm run tauri dev

node tools/verify/cdp.mjs --eval "pet.behavior.force('sit')" --wait 1500 --shot sitting.png
node tools/verify/bed.mjs                                # the whole bed sequence
node tools/verify/nap.mjs                                # checks whether the pet and the bed overlap
node tools/verify/menu.mjs                               # the menu to switch pets
node tools/verify/cdp.mjs --page bed --shot bed.png      # the bed window
powershell -File tools/verify/clickthrough.ps1
powershell -File tools/verify/input.ps1 -Action rub
```

The last two move the real cursor for a couple of seconds.
